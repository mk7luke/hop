One link. Every hop.

Where does this link actually go?

Paste a URL. Hop follows each redirect, then gives you the final address with tracking tags removed.

Works with JavaScript off. Hop does not store the link.

example.com with tags Two-hop demo

How

1

Paste a full http or https link. A bare host is treated as https.

2

Hop requests each stop and records the status, the host, and the next address.

3

Copy the clean link. Known tracker tags are listed under it. Unknown tags stay.

Limits

  • http and https only, port 80 and 443. No file links, no passwords in the URL.
  • Local, private, and link-local addresses are refused. That includes hosts that resolve there.
  • 6 hops. 4 seconds each. 30 checks per IP per hour.
  • Hop does not run page scripts. A meta refresh is shown and not opened.
  • This is not a safety check. Hop does not download the file, and it does not say a link is safe.
  • Links are not stored.
